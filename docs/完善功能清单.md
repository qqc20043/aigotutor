## 四、实施中踩到并修复的真实缺陷（累计 21 项）

### 批次 A（10 项）
1. Python 语法错误判 RE 而非 CE → 加 `ast.parse` 预检
2. TLE 卡死 40 秒 → 带超时的异步进程回收
3. MLE 误判 TLE → 实时采样后主动 kill
4. Java 全部编译失败 → `public class Main` 必须在 `Main.java`
5. Java 编译过但运行失败 → javac/java 版本错配，让 java 跟随 javac
6. BOM 导致 Java CE → 统一剥离
7. mock 推荐返回字符串 `"None"` → 候选键名兼容
8. 增量 JSON 数字提前闭合 → 要求数字后接分隔符
9. javac/java 版本误报 → 修正正则
10. schema 自愈调动态默认值崩溃 → 只接受静态默认值

### 批次 B（4 项）
11. esbuild 构建脚本被 pnpm 拦截 → `pnpm-workspace.yaml` 的 `allowBuilds`
12. 旧 `/` 路由抢占前端根路径 → 删除冲突路由
13. `vue-tsc` 抓到死代码与隐式 any → 修复
14. npm 官方源不通 → 固化 npmmirror

### 批次 C（6 项）
15. **任务 upsert 竞态**（压测抓到）→ `UNIQUE constraint failed: background_tasks.id`，改用数据库 upsert
16. **去重完全失效**（压测抓到）→ 10 个并发相同提交产生 10 条记录，改用临界区
17. **限流 sweep 永不生效** → 空桶判断错误（时间戳未 pop）
18. **指标空样本时不输出元信息** → 监控系统报"未知指标"
19. **删题 500** → ORM 把子行外键置 NULL 而列是 NOT NULL，加 `passive_deletes=True`
20. **seed 的 demo 不是管理员** → 管理后台无法演示

另修：`strip_html` 跳过实体解码、CF URL 正则、段标题 `startswith` 误判正文、样例标记匹配过宽。

### 收尾复核（1 项）
21. **`requirements.txt` 漏了 `alembic` 与 `psutil`** —— 这是最阴的一类缺陷：两者都写成可选导入，缺了不会崩，只会**静默降级**。`alembic` 缺失让迁移验收直接失败；`psutil` 缺失让 Windows 上的内存采样失效，MLE 用例被误判成 TLE（自测从 10/10 掉到 9/10）。两者已补进清单，并新增 `check_deploy.py` 断言把这类"静默降级"钉死在 CI 里。

## 五、已知边界（诚实声明）

| 边界 | 说明 |
|---|---|
| **subprocess 隔离弱** | 接口如实返回 `isolation: weak`。**公网部署必须切 `JUDGE_BACKEND=docker`**。 |
| **Docker 后端未实测** | 本机无 Docker，代码已实现但未在真实容器验证。 |
| **C++ 未实测** | 本机无 g++；已实现探测（缺失时明确报错），装上即自动可用。 |
| **多 worker** | 写锁与任务表是进程内的；`uvicorn --workers N` 需换 MySQL/Postgres 或 Redis 锁。 |
| **限流为单进程** | 同上，多 worker 时各进程独立计数，需 Redis 才能全局一致。 |
| **排行榜跨时区** | 窗口类排行按 UTC 日界，跨时区用户不完全可比 —— 已在响应里标注。 |
| **无向量检索** | 题库检索用 `LIKE` + 标签；错题聚类用标签组合指纹。 |
| **FSRS 为简化版** | 保留 S/D/R 三参数，行为正确但与 Anki 官方参数不可逐位对齐。 |
| **通知无推送** | 仅站内信；邮件/WebPush 未做。 |
| **导入不联网抓取** | 由用户粘贴题面，避免爬虫风险；自动抓取未做。 |
| **可选依赖静默降级** | `psutil`/`alembic`/`tzdata` 缺失不会崩，但会让内存判题、迁移、时区日界分别出错。已进 `requirements.txt` 并由 `check_deploy.py` 断言守护。 |
