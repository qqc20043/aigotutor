## 2. 快速上手

### 2.1 起后端

```bash
python run.py              # 默认 8000 端口；Windows 下已显式 ProactorEventLoop（reload 可用）
```

关键环境变量（`.env` 或进程环境，见 `app/config.py`）：
- `AIGOTUTOR_DB`：SQLite 路径（默认 `data/aigotutor.db`）
- `AIGOTUTOR_PROVIDER`：`mock|openai|anthropic|gemini`（默认 mock）
- `AIGOTUTOR_API_KEY` / `AIGOTUTOR_MODEL` / `AIGOTUTOR_BASE_URL`：真模型三件套
- `AIGOTUTOR_REDIS_URL`：默认 `redis://127.0.0.1:6379/0`；**Redis 不在也能跑**（自动降级进程内实现）
- `AIGOTUTOR_SECRET`：JWT/token 签名密钥（生产必须改）

Redis（可选但建议）：`D:\Redis\redis-server.exe --port 6379`

## 4. 核心设计决策（为什么这样做）

1. **策略归规则、表达归 LLM**：所有分数/判定先由规则引擎算定，LLM 只做润色或窗口内校正，且一切 LLM 输出可降级到规则模板。断网/超时/乱输出主链路不中断——`degraded=True` 对上层透明。
2. **两阶段评分**：judge 先规则基线，LLM 只能在窗口内修正（防模型瞎判）。
3. **内容寻址缓存 + 6h TTL**：Agent 结果按全部输入哈希缓存，数据变=键变，加长 TTL 无正确性风险（TTL 只是回收周期）。
4. **官方题解 AC 后解锁**：`problems.official_solution` 由详情接口门控——AC 过或管理员才拿到内容，未解锁只给 has 标记（内容不进响应，devtools 抓不到）。题解参考代码被测试强制逐用例验证，"经沙箱 AC"是硬承诺。
5. **FSRS 复习语义与 Anki 对齐**：lapses、搁置（suspended）、混排三路采题、练习配方存条件不存快照。
6. **MCP 与 Web 同口径**：MCP Server 不另写业务，直接复用 service 层同一个 SQLite 库。

## 6. 踩坑军规（最高价值章节，条条是血泪）

### 6.1 环境与进程

1. **Windows `run.py` 必须显式 ProactorEventLoop**——uvicorn reload/workers 在 Windows 选 SelectorEventLoop，不支持 `create_subprocess_exec`，判题沙箱全废（`NotImplementedError`）。
2. **run.py 多进程 worker 会在主进程被杀后留孤儿抢占 8000 端口**（openapi 还是旧路由=僵尸版本在应答）。重启必须按命令行清理 multiprocessing-fork 子进程。
3. **后台 bash 任务起的服务随会话回收被杀**——常驻服务必须 PowerShell `Start-Process` 独立进程；中文路径的 .ps1 会被 PS5.1 按 ANSI 读乱码，用 `-File` 跑。
4. **别从 Temp 目录跑 import 型脚本**——Temp 里的杂文件（如 struct.py）遮蔽标准库，深层 ImportError 伪装成莫名其妙的信息。
5. **git push 被墙是常态**——备用路径 `python /tmp/push_api.py`（REST API 逐提交推送，支持删除与指定提交）。推完用 `gh run list` 确认 CI。
6. **⚠️ 有并行镜像会话**——动 git 前先 `git log` 看有没有别人（另一个自己）新提交，避免覆盖。

### 6.2 数据库

7. **SQLite 单写锁三条纪律**：①审计日志等"顺手写"必须复用调用方的 db session（独立 session=锁冲突=静默丢日志）；②SSE/流式路径把所有写入合并到流结束后的**单一事务**；③`persist_task` 等高并发 INSERT 对 OperationalError 做 0.2/0.4/0.8s 退避重试，**重试前必须 rollback**。
8. **生产库若由 create_all 建出而 alembic_version 为空**：迁移会从 base 重放并撞 `table already exists`。方案：`alembic stamp head` 对齐标记（schema 已是 head 等价）。
9. **`create_problem` 内部会 json.dumps(samples)**——调用方必须传 list，传 dumps 过的字符串=双重编码=详情页 pydantic 500（题包 seed 踩过，现已自带检测自愈）。
10. **create_all 只建表不加列**——模型加字段必须配 Alembic 迁移（batch_alter_table 模式见 c3f8a2d94e17）。

### 6.3 测试

11. **coverage 用 `core = "sysmon"`**——默认 ctrace 在 asyncio 恢复的协程上漏记，此前所有"API 模块覆盖率低"都是虚低。
12. **首注册用户自动是管理员**——门控/权限类测试必须显式 `row.role = "user"` 降权，否则单文件跑测试时恰好首个注册=管理员，断言假挂。
13. **共享测试库的假设都要相对化**：seed 按标题跳过同名题（计数断言用 shadow titles 相对值）；相似题类测试 limit 给足（题库有规模后 top-5 假设不成立）；测试文件建题标题避开题包经典名。
14. **FSRS 语义**：rating=1 首次失败不计 lapse（要 4 次 rating=1 才能造 leech）；当天连续打分造不出 due 态（测试用 `_force_due` 回拨）。
15. **前端模板层 bug 只有浏览器 E2E 能抓**（例：`send($event)` 把 KeyboardEvent 当布尔传）。pytest 全绿≠前端对。
16. **`ruff format` 必须提交前跑**——CI 红灯同因已发生 4 次。

### 6.4 工具链

17. **heredoc/转义三层陷阱**：bash heredoc 吞 `\n`/引号；嵌套代码字符串（题解里的 ```python 块）需要文件里 `\\n` 两层转义才能让子进程源码拿到换行。**代码级修改一律用 Edit/Write 工具**；嵌套字符串里的换行 join 优先 `chr(10)` 彻底规避。
18. **`inspect.getsource` 只有函数本体**——题包 wrapper 提取 solve 源码时要自补模块级 import 并调用真实函数名。
19. **SPA 缓存**：HTML 必须 no-store；`router.onError` 识别 chunk 加载失败自动整页重载。"部分页面能用部分点不动"=旧 chunk 404 的特征指纹。
20. **Agent 显式短超时不重试**（ctx.timeout 非零时 TimeoutError 直接降级，否则 20s×3=60s）；带 LLM 的页面禁整页 loading，快数据先渲染、AI 数据渐进填充。
21. **judge 子进程剥离密钥环境变量**（weak isolation 下防 os.environ 窃取 key）——改 judge 环境时别把这个剥了。
22. **网关特性**：deepseek-v4.1-flash 小请求 3s，大结构化输出（推荐/路线图 JSON）30-60s——概览页 next/roadmap 已设 20s 快速降级，别挪高。

## 8. 面试演示剧本（这个项目怎么讲）

1. **一句话**：多智能体驱动的刷题平台，9 个 Agent 管学习路径，判题/复习/ gamification 全闭环，532 测试 93% 覆盖 CI 全绿。
